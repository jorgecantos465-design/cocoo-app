# Skill: Frontend UI - cocoo-app

## Objetivo
Mejorar la interfaz React/Tailwind manteniendo claridad, responsive y lectura rapida de numeros financieros.

## Cuando usarla
Usala para layout, estilos, componentes, estados visuales y responsive.

## Pasos obligatorios
- Revisar convenciones de `src/App.jsx` y `src/styles.css`.
- Mantener jerarquia visual clara.
- Probar mobile y desktop.
- Evitar decoracion que tape datos.

## Checklist antes de modificar
- El cambio no altera calculos.
- Se entiende el estado vacio, cargado y editando.
- No se toca `package.json`.

## Checklist antes de finalizar
- Build exitoso.
- Textos no se superponen.
- Numeros largos entran en sus contenedores.

## Errores que debe evitar
- Priorizar apariencia sobre legibilidad financiera.
- Crear componentes sin reutilizacion real.
- Ocultar acciones frecuentes.

## Comandos de verificacion
- `npm run build`
- `npm run dev`

## Formato de reporte final
- Pantallas ajustadas.
- Estados revisados.
- Verificacion responsive.
- Riesgos visuales.
