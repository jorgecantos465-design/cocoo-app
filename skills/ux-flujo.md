# Skill: UX y flujo - cocoo-app

## Objetivo
Hacer que cargar datos, entender el mes y leer el diagnostico sea directo para usuarios no tecnicos.

## Cuando usarla
Usala al cambiar pasos, labels, ayudas, orden de informacion o mensajes de diagnostico.

## Pasos obligatorios
- Definir tarea principal del usuario.
- Reducir decisiones innecesarias.
- Validar que cada numero tenga contexto.
- Mantener copy en espanol simple.

## Checklist antes de modificar
- Hay flujo actual identificado.
- Se conoce el punto de friccion.
- El cambio no exige conocimiento contable.

## Checklist antes de finalizar
- El usuario puede completar el flujo sin instrucciones externas.
- Los errores o vacios son comprensibles.
- El diagnostico explica causa, no solo resultado.

## Errores que debe evitar
- Usar jerga financiera sin explicacion.
- Pedir demasiados datos al inicio.
- Cambiar orden sin motivo observable.

## Comandos de verificacion
- `npm run dev`
- `npm run build`

## Formato de reporte final
- Flujo evaluado.
- Friccion reducida.
- Copy cambiado.
- Validacion manual.
